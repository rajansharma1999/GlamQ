# Admin Feature

## Scope
Platform Administration:
- Shop review, verification, and approvals.
- User management and account status.
- Booking overview, platform fee ledger (₹8/booking configurable parameter), dispute resolution.

## Planned Layer Structure:
- `presentation/`: Admin dashboard, shop approval queue, revenue and fee ledger screens.
- `domain/`: Admin models, platform metrics contracts.
- `data/`: Admin data repositories.
