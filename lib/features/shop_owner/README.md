# Shop Owner Feature

## Scope
Shop owner portal:
- Shop onboarding & profile configuration.
- Staff, service catalogue, working hours, and availability.
- Owner dashboard, daily overview, and basic earnings summary.

## Planned Layer Structure:
- `presentation/`: Shop owner dashboard, catalog editor, staff configuration, earnings screens.
- `domain/`: Shop management models, owner repository interfaces.
- `data/`: Shop owner remote repository implementation.
