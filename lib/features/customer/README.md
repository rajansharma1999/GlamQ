# Customer Feature

## Scope
Customer experience:
- Discovering salons, barbers, and beauty parlours.
- Browsing shop catalog, services, stylist availability.
- Customer dashboard and navigation.

## Planned Layer Structure:
- `presentation/`: Customer home, shop discovery, shop details screens, controllers.
- `domain/`: Customer models, shop query interfaces.
- `data/`: Remote shop repository implementation (Supabase queries).
